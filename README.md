# Freight-Forwarding-Dashboard
📊 Freight Data Analytics: Operational Data Insights Dashboard

A dynamic and interactive Power BI dashboard built to explore and analyze operational Freight application data. This dashboard focuses on key business metrics, data relationships, and system-level insights to support better decision-making and reporting efficiency.

🎯 Short Description / Purpose:

The Freight Analytics Dashboard is designed to visualize and analyze structured operational data from the freight application system, helping users understand key trends, relationships, and performance indicators across different modules.

It enables QA teams, business analysts, and stakeholders to quickly explore data from multiple sources (database and Excel) and identify inconsistencies, performance patterns, and operational insights.

🛠️ Tech Stack:

The dashboard was built using the following tools and technologies:

📊 Power BI Desktop – Primary tool for data visualization and dashboard development
🔄 Power Query – Data extraction, transformation, and cleaning (ETL process)
🧠 DAX (Data Analysis Expressions) – Used for calculated measures and dynamic insights
🗂️ Data Modeling – Relationships created between tables like Data_Summary, Freight_Data_Summary, etc.
📁 Data Sources – SQL Database & Excel files
📄 File Format – .pbix (development file), .png (dashboard preview)

🚀 Features / Highlights
🔍 Business Problem

Operational teams often struggle with fragmented data sources (SQL + Excel), making it difficult to maintain consistency, validate data relationships, and generate quick insights.

🎯 Goal of the Dashboard:

Provide a single unified view of SOL operational data
Enable comparison between database vs Excel-based datasets
Improve QA validation and data accuracy checks
Support faster reporting and decision-making

📊 Key Visuals & Insights:

📌 Data Summary Overview:

Total records across modules
Source-wise data distribution (Database vs Excel)
Summary-level KPIs for quick insights

🔗 Data Relationship View:
Mapping between SOL_Summary_Table and SOL_Data_Summary
Relationship validation for consistency checks

📈 Module-wise Analysis:
Breakdown of data by functional modules
Identifies high-volume and low-volume areas

⚠️ Data Quality Checks:

Missing/duplicate records identification
Mismatch detection between sources

📊 Trend & Pattern Analysis:

Time-based or category-based trends (if applicable)
Helps in identifying operational anomalies

💼 Business Impact & Insights:

✅ Improved QA Efficiency – Faster validation of data consistency across systems
📊 Better Decision Making – Centralized insights from multiple sources
🔍 Data Accuracy Monitoring – Identifies mismatches between SQL and Excel sources
⚡ Faster Reporting – Reduces manual effort in data analysis
🧠 Operational Visibility – Helps stakeholders understand system-level data flow
